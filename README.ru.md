# Численные методы: интерполяция и ОДУ

[English version](README.md)

Небольшая учебная коллекция на Python для экспериментов с интерполяцией, кубическими сплайнами и оценкой ошибки численного метода для жёсткого дифференциального уравнения.

## Состав

| Файл | Назначение |
|---|---|
| `mmc.py` | Интерполяционные эксперименты с равноотстоящими узлами и узлами Чебышёва, разделёнными разностями Ньютона и кубическими сплайнами. Результаты визуализируются графиками. |
| `MMC2.py` | Отдельный численный эксперимент с неявной схемой Эйлера: численное решение сравнивается с точным на нескольких шагах интегрирования. |

Это два самостоятельных задания, а не единое консольное приложение.

## Зависимости

Нужны Python 3, NumPy, Matplotlib и SciPy:

```bash
python -m pip install numpy matplotlib scipy
```

## Запуск

Из корня репозитория запускайте скрипты отдельно:

```bash
python mmc.py
python MMC2.py
```

Первый скрипт строит графики; второй выводит оценки ошибки для разных шагов. Команды соответствуют структуре исходников, но запуск в этой среде не проверялся.

## Ограничения

Это учебные эксперименты, а не готовая библиотека численных методов. Формулы, граничные случаи и точность реализации требуют независимой проверки; автоматические тесты в этой версии не добавлены.
